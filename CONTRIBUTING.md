# Contributing

Contributions are welcome, and they are greatly appreciated! Every little bit helps, and credit will always be given.

## Ways to Contribute

*   **Report Bugs:** If you find a bug, please open an issue and provide detailed information, including the steps to reproduce it.
*   **Suggest Enhancements:** If you have an idea to improve a script or add a new one, open an issue to discuss it.
*   **Submit Pull Requests:** If you want to contribute code, please follow the guidelines below.

## Pull Request Process

1.  **Fork the repository** and create your branch from `main`.
2.  **Make your changes.** Please ensure your code is well-commented, especially in harder-to-understand areas.
3.  **Ensure your script is robust.** Run your script through `shellcheck` to catch common issues and ensure it adheres to best practices.
4.  **Update the documentation.** If you've changed a script's behavior or added a new one, please update the `README.md` or any other relevant documentation.
5.  **Submit the pull request.** Provide a clear description of the problem and solution. Include the relevant issue number if applicable.

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms. Please see the `CODE_OF_CONDUCT.md` file for more information.

Thank you for your contributions!
